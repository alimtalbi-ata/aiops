# V8.0 Rebuild scope

V8.0 is a clean-slate reconstruction that keeps the best functional capabilities accumulated in V7.x while replacing runtime naming, boundaries, data ownership and deployment coupling.

Retained capability families: canonical Run/Incident lifecycle, Digital Twin, evidence provenance, policy gates, HITL, remediation/verification/reconciliation, Temporal durable execution, simulator/replay/story, Portal/Command Center, ITSM integration, observability, idempotency, checkpoints, receipts, synthetic E2E and audit tooling.

Legacy runtime names, networks, volumes and databases are not prerequisites for V8.

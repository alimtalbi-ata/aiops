# V7.7 Architecture Review

V7.7 hardens execution and integration boundaries.

## Outbox
Pending messages are leased for 60 seconds. A crashed dispatcher therefore does not permanently strand an item in `SENDING`. A lease owner is required for acknowledgement.

## Integration receipts
Successful delivery records an idempotent receipt before the outbox is acknowledged. This creates an auditable boundary between business state and external integration.

## AI decision path
Policy no longer receives a hard-coded live confidence. For LIVE execution it consumes the Intelligence result. The current built-in Intelligence adapter returns confidence 0 until a real model adapter is configured, therefore LIVE automatic execution remains fail-closed.

## Demo
DEMO/REPLAY/STORY remain simulation-only. The Worker may execute the corresponding workflow stages, but no production mutation adapter is enabled.

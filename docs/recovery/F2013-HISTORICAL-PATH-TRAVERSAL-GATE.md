# Contrôle des chemins historiques de captures F20.13

Les anciens manifestes Playwright peuvent contenir un chemin absolu `screenshot` sur l'hôte Debian. La simple extraction du basename d'un chemin malveillant pouvait masquer `..` dans le chemin d'origine. Le moteur `demo/star_legacy_png_verify.py` refuse désormais tout chemin historique non canonique, notamment les traversées `..`, séparateurs Windows, caractère NUL et chemins hors de `/home/aiops/` ; il ne lit les PNG que dans le dossier local explicitement fourni par l'opérateur. Deux tests couvrent le rejet de la traversée et le cas POSIX canonique. Ce contrôle garantit uniquement l'intégrité hors ligne des octets, jamais l'authenticité des captures applicatives ou du run métier. Vérifier la CI sur le SHA de ce commit avant qualification.

# V7.5 Architecture Review

V7.5 closes three functional gaps in the V7.4 baseline:

1. The Worker now invokes explicit RAG and Intelligence boundaries for RAG/Analyst/Critic stages.
2. A Policy block transitions the canonical Run to BLOCKED rather than leaving it RUNNING.
3. The Core exposes an outbox claim/ack protocol and Integration runs a dispatcher.

Simulation remains run-scoped. Evidence remains append-only/idempotent. Internal ports remain unexposed.

The Intelligence service deliberately reports UNKNOWN/zero-confidence until a real model adapter is configured; no fabricated model result is presented as real AI inference.

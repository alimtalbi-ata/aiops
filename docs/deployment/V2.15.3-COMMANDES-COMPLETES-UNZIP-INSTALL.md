## Linux / Debian 13

Depuis le répertoire où se trouve le ZIP :

```bash
set -euo pipefail
ZIP="AIOPS-KIT-DEPLOIEMENT-V2.15.3-PORTAIL-UNIQUE-20261026.zip"
unzip -tq "$ZIP"
unzip -q "$ZIP"
cd "AIOPS-KIT-DEPLOIEMENT-V2.15.3-PORTAIL-UNIQUE-20261026"
sha256sum -c 08-Manifestes/SHA256SUMS-V2.15.3.txt
cd 11-Installateur
chmod +x install-aiops-candidate.sh
sudo ./install-aiops-candidate.sh --audit
```

Après inspection de l'audit et autorisation explicite :

```bash
sudo ./install-aiops-candidate.sh --install --dest /opt/aiops-candidate
```

## Windows PowerShell (extraction et inventaire SHA-256)

```powershell
$zip = '.\AIOPS-KIT-DEPLOIEMENT-V2.15.3-PORTAIL-UNIQUE-20261026.zip'
Expand-Archive -LiteralPath $zip -DestinationPath . -Force
Set-Location '.\AIOPS-KIT-DEPLOIEMENT-V2.15.3-PORTAIL-UNIQUE-20261026'
Get-ChildItem -Recurse -File | Get-FileHash -Algorithm SHA256
```

# AIOps V2.15.4 — durcissement de l'installateur candidat

Le script `deploy/kit/install-aiops-candidate.sh` a été durci pour réduire le risque de perte de travail local lors de la mise à jour d'un checkout candidat.

- Refuse une destination qui est un lien symbolique.
- Vérifie l'origine Git du checkout existant.
- Refuse tout checkout existant avec changements suivis ou non suivis (sortie `git status --porcelain` non vide) au lieu de réinitialiser la branche.
- Vérifie que la branche après checkout est celle attendue.
- Continue de séparer `--audit` (lecture seule) de `--install` (récupération du code candidat uniquement).

## Vérification

La syntaxe Bash et le manifeste SHA-256 du kit cumulatif local V2.15.4 sont contrôlés avant livraison. La CI déclenchée par le commit du script doit être vérifiée indépendamment. Aucun test de cette branche ne remplace l'E2E live sur Debian.

## Limites inchangées

Le script ne démarre pas Docker Compose, ne touche pas à systemd ni au pare-feu, ne crée aucun port supplémentaire, ne monte pas les routes NOC dans le portail réel et ne redémarre aucun service. Point d'accès cible unique : `http://10.79.94.202:17777/`.

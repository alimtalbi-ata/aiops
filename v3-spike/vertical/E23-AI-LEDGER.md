# E23 durable AI invocation telemetry — laboratory contract

Completed reviews are recorded atomically in the existing dedicated EnterpriseClock SQLite database, with server-generated review ID, E18 correlation digest, model context digest, run IDs and strict per-invocation allowlisted receipts. No raw prompt/output, credentials, cost/TTFT estimates or caller receipt API. Bounded capacity (10,000 reviews, aggregate at most 100 explicit IDs). Aggregation per role/model/prompt version; nearest-rank p50/p95, complete usage totals null on missing samples, separately labeled partial reported total. Hashes detect accidental tampering, not privileged rewriting. No in-flight recovery or exact-once invocation guarantee; a crash before commit can lose telemetry, capacity race fails closed. No tenant ACL or UI yet. Actual HTTP fixture tests, SQLite reopen and separate backup/restore. Real LLM telemetry integration after E21.
